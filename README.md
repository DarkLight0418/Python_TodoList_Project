# Python Tkinter Todo List

Python `tkinter`를 사용해 만든 학습용 Todo List 데스크톱 애플리케이션입니다.  
사용자는 GUI 화면에서 할 일을 추가하고, 선택한 항목을 삭제하고, 현재 목록을 텍스트 파일에 저장할 수 있습니다.

이 프로젝트는 완성형 생산성 도구라기보다는 **Python GUI 프로그래밍, 파일 입출력, 실행 파일 패키징 흐름을 연습하기 위한 미니 프로젝트**입니다.

---

## 1. 프로젝트 목적

이 프로젝트의 목적은 단순한 Todo List 기능을 직접 구현하면서 Python 데스크톱 애플리케이션의 기본 흐름을 익히는 것입니다.

주요 학습 목표는 다음과 같습니다.

- `tkinter`를 활용한 GUI 화면 구성
- 버튼 클릭 이벤트 처리
- `Listbox`와 `Scrollbar`를 사용한 목록 표시
- 사용자 입력 팝업 처리
- 텍스트 파일 기반 데이터 저장 및 불러오기
- PyInstaller를 활용한 `.exe` 실행 파일 패키징 실험

---

## 2. 주요 기능

| 기능 | 설명 |
| --- | --- |
| Todo 목록 불러오기 | 프로그램 실행 시 저장된 텍스트 파일에서 기존 Todo 목록을 불러옵니다. |
| Todo 추가 | 팝업 입력창을 통해 새로운 할 일을 입력하고 목록에 추가합니다. |

| 종료 확인 | 종료 버튼 클릭 시 확인 메시지를 띄운 뒤 프로그램을 종료합니다. |

## 4. 프로젝트 구조

현재 프로젝트는 다음과 같은 구조로 구성되어 있습니다.

```text
Python_TodoList_Project/
├─ TodoList.py              # tkinter GUI 실행 파일
├─ todo_func.py             # Todo 목록 파일 입출력 로직
├─ txtTodo/
│  └─ TodoList.txt          # Todo 저장 파일
├─ temp_files/              # 실험/연습용 코드
├─ build/                   # PyInstaller 빌드 산출물
└─ dist/                    # PyInstaller 실행 파일 산출물
```

핵심 파일은 `TodoList.py`와 `todo_func.py`입니다.

### `TodoList.py`

GUI 화면과 사용자 이벤트를 담당합니다.

- 메인 윈도우 생성
- Label, Button, Listbox, Scrollbar 구성
- Todo 추가 팝업 실행
- 선택 항목 삭제 처리
- 현재 Todo 목록 저장 요청
- 종료 확인 메시지 처리

### `todo_func.py`

Todo 데이터를 텍스트 파일로 저장하고 불러오는 역할을 담당합니다.

- 저장 디렉터리 확인 및 생성
- Todo 저장 파일 생성
- 파일에서 Todo 목록 불러오기
- 현재 Todo 목록을 파일에 저장하기

## 5. 실행 방법

Python이 설치된 환경에서 프로젝트 폴더로 이동한 뒤 다음 명령어를 실행합니다.

```bash
python TodoList.py
```

실행 후 GUI 창에서 다음 작업을 할 수 있습니다.

1. `할 일 추가` 버튼을 눌러 Todo를 입력합니다.
2. 목록에서 항목을 선택한 뒤 `선택 항목 삭제` 버튼으로 삭제합니다.
3. `저장` 버튼을 눌러 현재 Todo 목록을 파일에 저장합니다.
4. `종료` 버튼을 눌러 프로그램을 종료합니다.

## 6. 데이터 저장 방식

현재 Todo 목록은 별도 데이터베이스 없이 텍스트 파일에 저장됩니다.

기본 저장 경로는 다음과 같습니다.

```text
./txtTodo/TodoList.txt
```

저장 버튼을 누르면 현재 `Listbox`에 표시된 Todo 항목들이 한 줄씩 텍스트 파일에 기록됩니다.

예시:

```text
파이썬 공부하기
과제 제출하기
운동하기
```

## 9. 현재 한계점

이 프로젝트는 학습용으로 제작되었기 때문에 다음과 같은 개선 여지가 있습니다.

### 1) GUI 코드와 데이터 처리 코드의 책임 분리가 부족함

현재 `TodoList.py`에서 화면 처리뿐 아니라 Todo 목록 데이터에도 직접 접근합니다.

예를 들어 GUI 클래스가 `self.todo_list.todo_list.append(task)`처럼 내부 리스트 구조를 직접 알고 있습니다.  
나중에 기능이 커질 경우 GUI, 비즈니스 로직, 저장 로직을 분리하는 편이 더 유지보수하기 좋습니다.

### 2) Todo 목록이 클래스 변수로 관리됨

`todo_func.py`에서 Todo 목록이 클래스 변수로 선언되어 있어 여러 객체가 생성될 경우 상태가 공유될 수 있습니다.

학습용 프로젝트에서는 큰 문제가 되지 않지만, 구조적으로는 인스턴스 변수로 관리하는 편이 더 안전합니다.

### 3) 파일 경로 처리 방식이 혼재되어 있음

현재 저장 경로가 `./txtTodo/TodoList.txt`, `todo_list.txt`, PyInstaller용 `resource_path()` 등 여러 방식으로 사용됩니다.

이로 인해 개발 환경과 실행 파일 환경에서 저장 위치가 달라질 수 있습니다.

### 4) 입력값 검증과 예외 처리가 부족함

현재는 기본적인 입력과 저장은 가능하지만 다음과 같은 검증이 부족합니다.

- 공백 문자열 입력 방지
- 중복 Todo 처리 정책
- 파일 저장 실패 시 예외 처리
- 저장하지 않고 종료할 때 경고 처리

### 5) 프로젝트 폴더 정리가 필요함

현재 프로젝트에는 실험 파일, 빌드 산출물, 실행 파일이 함께 포함되어 있습니다.

GitHub에 정리해서 올릴 경우 `temp_files`, `build`, `dist` 등을 분리하거나 `.gitignore`로 관리하는 것이 좋습니다.

## 11. PyInstaller 패키징

PyInstaller를 사용하면 Python 파일을 Windows 실행 파일로 패키징할 수 있습니다.

예시 명령어는 다음과 같습니다.

```bash
pyinstaller -F -w -n Todo_list TodoList.py
```

옵션 의미는 다음과 같습니다.

| 옵션 | 의미 |
| --- | --- |
| `-F` | 하나의 실행 파일로 패키징합니다. |
| `-w` | 콘솔 창 없이 GUI 프로그램으로 실행합니다. |
| `-n Todo_list` | 실행 파일 이름을 `Todo_list`로 지정합니다. |

단, 현재 구조에서는 PyInstaller 실행 환경과 개발 환경의 파일 경로가 달라질 수 있으므로, 패키징 전 저장 파일 경로 처리 방식을 정리하는 것이 좋습니다.
